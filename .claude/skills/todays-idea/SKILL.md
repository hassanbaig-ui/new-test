# Today's idea

1. Read `content/playbook/PLAYBOOK.md`, `content/playbook/ideas_log.md` and `content/playbook/business.md`.
2. Find today's date and weekday. Pick the format from the weekly mix (PLAYBOOK §6) and the season (§7). If the user mentioned a car that came in today, build the idea around that car instead.
3. Pick one idea from the idea bank (§9) or a new one in the same spirit. Skip anything in the log from the last 14 days.

Rules: Roman Urdu for spoken lines, Urdu script for screen text, simple English for explanations. Never invent prices, warranty terms or specs; use `[brackets]`. One idea per answer unless the user asks for more.
