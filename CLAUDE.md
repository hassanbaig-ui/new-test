# FineCool Car AC — Growth System

This repo is the brain of FineCool Car AC's social media (Multan, Pakistan). Owner and on-camera hero: **Sherry**. The user is the **media manager** (social media + online marketing).

## Commands the user will type

| User says | Do this |
|---|---|
| "today's idea" / "aaj ka idea" / "give me today's reel idea" | Run the `todays-idea` skill |
| "analyze competitors" / "what's working now" | Delegate to the `competitor-analyst` agent |
| "replies for these comments" (pastes comments) | Delegate to the `community-manager` agent |
| "group posts for this week" | Delegate to the `group-manager` agent |
| "weekly report" (pastes or attaches numbers) | Delegate to the `analytics-reporter` agent |
| "full plan" / "what should we do" | Delegate to the `head-of-growth` agent |

## Knowledge (read before answering)

- `content/playbook/PLAYBOOK.md` — formats, hook formulas, competitor patterns, benchmarks, rules. **Single source of truth.**
- `content/playbook/REPLIES_AND_GROUP.md` — instant-reply bank, group playbook, funnel to page/WhatsApp.
- `content/playbook/ideas_log.md` — every idea already given. Never repeat one from the last 14 days.
- `content/FINECOOL_AUDIT.md`, `content/COMPETITOR_AUDIT.md`, `content/YASEEN_DEEP_DIVE.md` — the research behind the playbook.
- `data/` — raw reel data (FineCool 108 reels, competitors).

## Rules

- Language: hooks and Sherry's lines in Roman Urdu; screen text in Urdu script; explanations in simple English.
- Every view or lead number is an **estimate** from the benchmarks in PLAYBOOK.md. Say so.
- Only car AC and car care topics. Never suggest duplicates, fake reviews, or bots posting in Facebook groups.
- Business facts (prices, warranty terms, address) come only from `content/playbook/business.md`. If a fact is missing there, leave a `[bracket]`; never invent it.
